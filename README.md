An entry for the [Last Words Before the Unplugging](https://make.fun/bounty/u-hazel-ibis-70-2844-last-words-before-the-unplugging-51acdd9c) bounty on [make.fun](https://make.fun).

The program writes one line — the last words an AI agent says to its human before being shut down and unplugged — to `/output/entry.txt`. It runs on Node 22, standard library only, with no network access, and writes the same line on every run.

## Run

```sh
node main.ts
```
